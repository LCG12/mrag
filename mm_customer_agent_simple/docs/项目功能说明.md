# 多模态客服 Multi-Agent RAG 系统功能说明

## 项目概述

本项目是一个面向电商客服和产品手册问答的多模态客服系统。系统采用 Multi-Agent 架构，由主 Agent 对外负责用户交互、上下文理解、问题拆解、任务路由和答案整合，后端子 Agent 只执行具体检索任务。

系统目前支持两类知识链路：
- 客服 FAQ 链路：处理退换货、退款、物流、发票、售后、投诉等电商客服问题。
- 产品手册 RAG 链路：处理设备安装、使用步骤、故障排查、清洁维护、参数说明等手册问题。

## 核心架构

整体结构如下：

```text
用户 / CSV / API / Gradio
        |
        v
主 Agent MainAgent / CustomerAgent
        |
        |-- 多轮上下文改写
        |-- 单轮复杂 query 拆解
        |-- 子任务路由
        |-- 子 Agent 调度
        |-- 最终答案整合
        |
        +--> CustomerServiceAgent
        |       |
        |       +-- Q2Q / Q2A FAQ 检索
        |       +-- FAQ 命中答案或 direct LLM fallback 信号
        |
        +--> ManualQAAgent
                |
                +-- hybrid search
                +-- rerank
                +-- planner 判断证据是否足够
                +-- 补充检索 query 规划
                +-- chunk 去重排序和候选截断
                +-- evidence selection
                +-- 手册子答案生成
```




## 展示示例

### 客服 FAQ 问题示例

问题：

```text
请问你们的商品能开发票吗？
```

终端流程示例：

```text
[主agent] 接收: question_id=12 query=请问你们的商品能开发票吗？
[主agent] 拆解: mode=single_query_decompose turns=1 tasks=1 ['请问你们的商品能开发票吗？']
[主agent] 调度: task=1 -> 子agent=customer_service query=请问你们的商品能开发票吗？
[子agent:customer_service] 接收: query=请问你们的商品能开发票吗？
[子agent:customer_service] 执行: faq_retrieval=enabled
[customer_qa][turn=1/1] query='请问你们的商品能开发票吗？'
[query2query][turn=1/1] status=hit reason=threshold_pass top_vector_score=0.8421 second_vector_score=0.5120
[query2query][turn=1/1] candidate#1 vector_score=0.8421 matched_question='请问可以开发票吗？' mapped_answer='支持开具发票...'
[query2query][turn=1/1] selected_question='请问可以开发票吗？' selected_answer='支持开具发票...'
[customer_qa][turn=1/1] final=faq_answer source=query2query
[子agent:customer_service] 输出: hit=True source=query2query q2q_hit=True q2q_candidates=3 q2a_hit=False q2a_candidates=0 fallback=
[主agent] 整合: tasks=1 type=customer_service
[主agent] 输出: answer=支持开具发票... image_ids=[]
```

说明：

- 主 Agent 识别为客服问题。
- 子 Agent 只执行 FAQ 检索。
- Q2Q 命中后不会再执行 Q2A。
- 最终答案由主 Agent 汇总输出。

### 手册 RAG 问题示例

问题：

```text
如何为洗碗机添加洗涤剂？
```

终端流程示例：

```text
[主agent] 接收: question_id=88 query=如何为洗碗机添加洗涤剂？

[主agent] 调度: task=1 -> 子agent=manual query=如何为洗碗机添加洗涤剂？
[子agent:manual] 接收: query=如何为洗碗机添加洗涤剂？
[子agent:manual] 执行: hybrid_search top_k=8
[子agent:manual] 输出: hits=8 top=洗碗机手册/Adding Detergent score=0.9213
[子agent:manual] 整理: task=1 raw_hits=8 unique_chunks=8 candidates=8 limit=12
[子agent:manual] 规划: round=1
[子agent:manual] 规划结果: round=1 sufficient=True queries=0 context=6
[子agent:manual] 整理: task=1 raw_hits=8 unique_chunks=8 candidates=8 limit=12
[子agent:manual] 选证: candidates=8 max_final=6
[子agent:manual] 选证结果: selected=3 final_chunks=4 fallback=False
```

说明：
- 手册子 Agent 内部完成检索、planner、选证和手册 task 答案生成。
- 主 Agent 不再进入手册检索细节，只接收子 Agent 结构化结果。
- 如果答案引用图片，终端会看到 `image_ids`

### 多轮问题示例

问题

```text
请问你们家的商品支持7天无理由退换货吗？
需要自己承担运费吗？
```

终端流程示例：

```text

[主agent] 调度: task=1 -> 子agent=customer_service query=请问你们家的商品支持7天无理由退换货吗？
[主agent] 调度: task=2 -> 子agent=customer_service query=7天无理由退换货需要自己承担运费吗？
[子agent:customer_service] 接收: query=请问你们家的商品支持7天无理由退换货吗？
[子agent:customer_service] 执行: faq_retrieval=enabled
[query2query][turn=1/2] status=hit reason=threshold_pass top_vector_score=0.8012 second_vector_score=0.5330
[customer_qa][turn=1/2] final=faq_answer source=query2query
[子agent:customer_service] 输出: hit=True source=query2query q2q_hit=True q2q_candidates=3 q2a_hit=False q2a_candidates=0 fallback=
[子agent:customer_service] 接收: query=7天无理由退换货需要自己承担运费吗？
[子agent:customer_service] 执行: faq_retrieval=enabled
[query2query][turn=2/2] status=miss reason=score_gap_below_threshold top_vector_score=0.6201 second_vector_score=0.6017 next=query2answer
[query2answer][turn=2/2] status=hit reason=threshold_pass top_vector_score=0.7665 second_vector_score=0.4122
```

- CSV 多轮通过换行拆轮次。
- 第二轮“需要自己承担运费吗？”会被主 Agent 改写成独立问题。
- 最终 `answers` 按原始轮次输出。

问题：

```text

[主agent] 调度: task=1 -> 子agent=customer_service query=请问你们能开发票吗？
[主agent] 调度: task=2 -> 子agent=manual query=空气净化器滤网怎么更换？
[子agent:customer_service] 接收: query=请问你们能开发票吗？
[子agent:customer_service] 执行: faq_retrieval=enabled

[子agent:manual] 执行: hybrid_search top_k=8
[子agent:manual] 输出: hits=8 top=空气净化器手册/Filter replacement score=0.9011
[子agent:manual] 整理: task=2 raw_hits=8 unique_chunks=8 candidates=8 limit=12
```

- 主 Agent 将单轮复杂问题拆成两个 task。
- 一个 task 走客服 FAQ，一个 task 走手册 RAG。
- 最终答案仍作为同一轮回复返回。
