# 图片输入与 OCR/VLM 图文增强功能说明

## 功能简介

原系统只支持文本问题，主 Agent 无法直接处理用户上传的图片。新增图片输入能力后，用户可以同时提交“问题 + 图片”，主 Agent 会先调用 OCR 和 VLM 获取图片信息，再将图片理解结果与原始问题结合，改写成新 query，继续进入原有客服 FAQ 或手册 RAG 流程。

其中：

- OCR 负责读取图片中的文字、标签、错误码、订单信息等可见文本。
- VLM 负责理解图片中的产品、部件、破损、错发、操作场景等视觉内容。
- 图片信息不会直接作为最终答案，而是用于补全用户问题、辅助路由和检索。

## 实现流程

整体流程如下：

```text
用户提交：原始问题 + 图片
        |
        v
主 Agent 接收图片输入
        |
        v
ImageUnderstandingTool 编排 OCR + VLM
        |
        v
生成 image_observation
        |
        v
AnswerGenerator.rewrite_query_with_image_context()
将原始问题 + 图片理解结果改写成 query
        |
        v
结合历史上下文做多轮改写，得到 final_query
        |
        v
assess_query_actionability() 判断信息是否足够继续
        |
        +-- 信息不足：直接追问
        |
        +-- 信息足够：任务拆解、路由、客服 FAQ 或手册 RAG
```

在 Gradio 中，用户提交图片后，对话框会同时展示用户上传的图片和文字问题。终端日志会打印图片理解、query 改写、可询问性判断、路由和子 Agent 执行结果，便于调试整个链路。

## 示例一：错发商品客服场景

图片：

<img src="D:\temp-du\extra\mmagentic_rag-完结\4mmagenic_rag\mm_customer_agent_simple\test_images\test1.png" alt="test1" style="zoom: 25%;" />

用户问题：

```text
这个和我买的不一样，接下来怎么办
```

图片理解摘要：

- 图中包含订单摘要。
- 订购商品是黑色耳机。
- 实际收到的是无线鼠标。
- 图中有“不匹配”线索和订单号 `A8-24XX`。

改写后的 query：

```text
我订购的商品是黑色耳机，但收到的是无线鼠标，订单摘要中明确写着“不匹配”，包裹标签写的是“耳机”，订单号是 A8-24XX，接下来怎么办？
```

进入链路：

```text
customer_service
```

最终回答示例：

```text
您好，感谢您及时反馈发错货的情况。针对您订单号 A8-24XX 中收到无线鼠标而非黑色耳机的问题，我们会尽快为您核实处理。

请您保留包裹外包装、面单、收到的无线鼠标实物，以及订单页面截图。如果方便，也请补充一张能清楚展示商品和包装标签的照片或开箱视频。我们会根据订单信息、仓库出库记录和物流交接信息进行核查，并根据核查结果为您安排更换正确商品、补发或其他售后处理。
```

这个示例中，原始问题里的“这个”本身不明确。引入图片理解后，主 Agent 能从图片中补全“订购耳机但收到鼠标”的事实，再把问题交给客服链路处理。

## 示例二：滤网更换手册场景

图片：

<img src="D:\temp-du\extra\mmagentic_rag-完结\4mmagenic_rag\mm_customer_agent_simple\test_images\test2.png" alt="test2" style="zoom:25%;" />

用户问题：

```text
这个咋换
```

图片理解摘要：

- 图中显示设备出风口。
- 图中有脏污空气滤网。
- 用户问题中的“这个”被补全为“空气滤网”。

改写后的 query：

```text
图中显示设备出风口下方有脏污空气滤网，这个咋换？
```

进入链路：

```text
manual
```

最终回答示例：

```text
您好，感谢您的咨询！关于您提到的设备出风口下方有脏污空气滤网，以下是更换滤网的操作步骤：

1. 请先拔下设备电源插头，确保断电操作，保障安全。
2. 双手握住设备上盖并向上拉起。
3. 握住背部滤网盖把手并向前拉出。
4. 取出已脏污的滤网。
5. 安装新滤网时，请确认滤网方向正确，将滤网上下推入设备，确保贴合紧密。
6. 装回滤网盖，确认盖板固定到位后再重新通电使用。
```

这个示例中，图片理解把“这个咋换”补全成“空气滤网怎么换”，随后进入手册 RAG 链路。最终步骤仍由手册证据支持，用户可见回答中不会暴露 `OCR`、`VLM`、`image_observation` 等内部调试字段。
