# 拆卸旧温控器

**关闭电源：**

为保护您自身及设备安全，请在断路器箱或控制供暖 / 制冷系统的开关处关闭电源。

【Manual36_4】

**确认系统已关闭：**

调节旧温控器温度。若 5 分钟内未听到系统启动，则电源已关闭。

【Manual36_5】

**拆卸旧温控器面板：**

大多数温控器可握住面板轻轻拉下即可拆卸。部分温控器可能配有螺丝、按钮或卡扣。

【Manual36_6】

此时请勿拆卸温控器上的任何电线！

【Manual36_7】

**确认无 120 / 240 伏电线：**

请检查以下问题：

- 是否有带线帽的粗黑色电线？
- 您的温控器电压是否为 120 伏或更高？

若任一问题答案为“是”，则您的系统为线电压系统，本温控器不适用。

【Manual36_8】

**拍摄当前接线照片：**

务必拍下电线插入端子旁的字母标识。这将为后续接线提供参考。

**提示：** 若电线颜色褪色，或两个端子的电线颜色相同，请使用包装内提供的电线标签标记每根电线。

【Manual36_9】

**拆除所有跨接线：**

跨接线用于连接两个端子，外观类似小订书钉或彩色电线。继续操作前必须拆除。使用螺丝刀将电线从端子上松开。

【Manual36_10】

RTH 7500 型温控器无需跨接线。

**记录以下端子是否有电线：**

计数时请勿包含跨接线。本温控器无需跨接线。

【Manual36_11】

**记录电线颜色：**

勾选连接至端子的电线，并在勾选旁写下电线颜色。计数时请勿包含跨接线。勾选适用选项，并非全部适用。

【Manual36_12】

RTH 7500 型温控器不支持 L / A、S 或 U 端子。若有电线连接至未列出的端子，您需要额外的接线支持，本温控器方可正常使用。

**断开电线并拆卸旧墙座：**

使用螺丝刀将电线从端子松开。然后，使用电线标签在断开时标记每根电线。电线标签上的字母应与端子字母一致。

**提示：** 为防止电线缩回墙内，可将电线缠绕在铅笔上。

# 安装温控器

【Manual36_14】

**整理并将电线穿过 UWP 底座：**

打开 UWP 底座，将成束电线从底座背面穿过。确保每根电线至少露出 1/4 英寸，便于插入电线端子。

【Manual36_15】

**安装墙塞：**

建议使用包装盒内提供的墙塞安装温控器。您可使用 UWP 底座标记墙塞安装位置。

1. 校准墙座水平。
2. 用铅笔标记墙塞位置。
3. 钻孔。
4. 插入墙塞。
5. 确保墙塞与墙面齐平。

**提示：** 使用 7/32 英寸钻头。

【Manual36_16】

**设置 R 开关位置并插入 R 线：**

根据前面记录的接线情况，上下拨动 R 开关。将电线插入 UWP 底座端子的内孔。电线插入后，卡舌会保持下压状态。

**若仅有 1 根 R 线（R、Rh 或 Rc）：**

【Manual36_17】

1. 将 R 开关拨至向上位置。

【Manual36_18】

2. 将 R 线（R、Rh 或 Rc）插入 R 端子。

**若有 2 根 R 线（R 或 Rh，以及 Rc）：**

【Manual36_19】

【Manual36_20】

# 系统运行设置

**系统运行设置：**

1. 按模式键循环切换至下一个可用系统模式。
2. 循环切换直至显示所需系统模式并保持激活状态。

**注：** 可用系统模式因型号及系统设置而异。

【Manual36_29】

**系统模式：**

- 自动：温控器根据需要自动选择供暖或制冷。
- 供暖：温控器仅控制供暖系统。
- 制冷：温控器仅控制制冷系统。
- 应急供暖：仅适用于带辅助加热的热泵。温控器控制辅助加热，不使用压缩机。
- 关闭：供暖和制冷系统关闭。若风扇设置为开启或循环模式，风扇仍可运行。

**注：** 由于压缩机保护，供暖 / 制冷指示灯会闪烁 5 分钟。

**风扇运行设置：**

1. 按风扇键循环切换至下一个可用风扇模式。
2. 循环切换直至显示所需风扇模式并保持激活状态。

**注：** 可用风扇模式因系统设置而异。

【Manual36_30】

**风扇模式：**

- 自动：仅在供暖或制冷系统运行时风扇启动。
- 开启：风扇持续运行。
- 循环：风扇随机运行约 33% 的时间。

# 程序日程

您可每天设置四个时间段，工作日和周末可设置不同参数。建议使用预设设置，可有效降低供暖 / 制冷能耗。

**日程时段说明：**

- 起床：设置起床时间及早晨离家前的所需温度。
- 离家：设置离家时间及外出时的所需温度，通常为节能温度。
- 回家：设置回家时间及晚上就寝前的所需温度。
- 睡眠：设置就寝时间及夜间所需温度，通常为节能温度。

# 接线参考

**常规系统接线：**

备用接线（常规系统）。若标签与端子不匹配，请按图连接电线，并参考下方注释。

**注释：**

1. 若必须同时连接 R 和 Rc 电线，将 R 滑动开关拨至向下位置（2 根电线）。
2. 若旧温控器同时有 R 和 RH 电线，将 R 滑动开关拨至向下位置（2 根电线）。然后将 R 线连接至 Rc 端子，RH 线连接至 R 端子。
3. 若旧温控器仅有 1 根 C 或 C1 电线，将其连接至 C 端子。若旧温控器有 2 根 C 或 C1 电线，分别用电工胶带包裹且不连接。

【Manual36_34】

**热泵系统接线：**

将每根标记电线与新温控器上的相同字母匹配，将电线插入对应端子。

**注：** 若插入电线困难，可按下对应端子旁的端子按钮。

**标签不匹配：** 若标签与温控器字母不匹配，请参阅备用接线说明。

【Manual36_35】

**备用接线（仅适用于热泵）：**

**注释：**

1. 保持 R 滑动开关在向上位置（1 根电线）。
2. 若旧温控器同时有 V 和 VR 电线，请立即停止并联系专业安装人员协助。
3. 若旧温控器有单独的 O 和 B 电线，将 B 电线连接至 C 端子。若 C 端子已连接其他电线，请立即停止并联系专业安装人员协助。
4. 若旧温控器有 Y1、W1 和 W2 电线，请立即停止并联系专业安装人员协助。

**智能响应技术：**

该功能可让温控器“学习”炉子和空调达到程序设定温度所需的时间，确保在您设定的时间达到目标温度。

例如：将起床时间设为早上 6 点，温度设为 70°F。供暖系统会在 6 点前启动，确保您 6 点起床时温度已达到 70°F。系统在预定时间段前启动时会显示“恢复中”提示。

**更换电池：**

温控器需电池供电。电池低电量图标出现时请立即更换新电池。该图标会在电池耗尽前约两个月显示。

即使未出现电池低电量图标，也应每年更换一次电池，或离家超过一个月前更换。

若两分钟内完成电池更换，无需重新设置时间和日期。所有其他设置将永久存储在内存中，无需电池供电。

**故障排除：**

若温控器出现问题，请尝试以下建议。大多数问题均可快速简便解决。

**屏幕空白：**

若使用电池供电，请确保已正确安装全新 AA 碱性电池。

**无法将系统设置切换至制冷模式：**

检查系统设置选项 220，确保设置为 1 或 2。

**需要供暖时风扇不启动：**

检查系统设置选项 205，确保设置与您的供暖设备匹配。

**制冷模式下供暖系统运行：**

检查系统设置选项 200 或 218，确保设置与您的供暖和制冷设备匹配。

**供暖或制冷系统无响应：**

按系统键将系统设置为供暖，并确保温度设定高于室内温度。若使用制冷模式，则确保温度设定低于室内温度。

同时检查断路器，必要时复位。确保供暖和制冷系统的电源开关已打开。确保炉门紧闭。等待 5 分钟让系统响应。

**屏幕上“供暖开启 / 制冷开启”闪烁：**

压缩机保护功能已启动。等待 5 分钟让系统安全重启，避免损坏压缩机。

**热泵问题：**

若供暖模式吹冷风，或制冷模式吹热风，请检查系统设置选项 200 或 218，确保设置与您的供暖和制冷设备匹配。

**警告：触电风险**

可能导致触电或设备损坏。开始安装前请断开电源。

**警告：汞处理提示**

若本产品更换的控制器内含有密封管汞，请不要将旧控制器丢弃。请联系当地废物管理部门了解回收及正确处理方法。
